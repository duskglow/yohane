# tiff

## T2 trim (2026-11-24): tiffgt, the OpenGL viewer

**Bootstrap only (decisions 16 and 24).** Yohane builds tiff without tiffgt, the OpenGL viewer, because it pulls in GLUT, Mesa and X. Found with
`tools/builddeps` and the min-cut analysis of 2026-11-24: T2 went from 833 sources to 269 with this batch.

**How:** `drop-build-deps` lists `freeglut3-dev`, `libglu1-mesa-dev`, `libxi-dev`; `tools/buildone` removes them from `debian/control` with `tools/trimcontrol`. The binary packages that need them may then fail to build; if so, a patch under `patches/` drops them from `debian/control` too, and this section says which.

**Restore** in the full pass, or when a package Yohane ships needs it: remove those names from `drop-build-deps`.

**Patch (2026-11-24):** `patches/0001-no-libtiff-opengl.patch` drops the `libtiff-opengl` package (it holds only
tiffgt, which isn't built without GLUT), so the build doesn't fail on an empty package.

## 0002: empty man directories under nodoc (2026-11-24)

**Problem.** Every bootstrap build uses `nodoc` (decision 15). The man pages are generated by sphinx, a `<!nodoc>`
build dependency, but `libtiff-dev.install` and `libtiff-tools.install` name `usr/share/man/man3` and
`usr/share/man/man1`, so `dh_install` failed on missing files.

**Change.** `patches/0002-nodoc-empty-man-dirs.patch` creates the two empty directories before `dh_install` under
nodoc. A normal build is unchanged.

**Patch `0003-libtiff-doc-nodoc.patch`:** marks `libtiff-doc` `Build-Profiles: <!nodoc>`. Under nodoc the manual isn't
built, and the indep build failed in dh_install (`usr/share/doc/libtiff-doc/manual/` missing). With nodoc, tiff has
no arch:all packages to build.
